# Звуки бара

Положи сюда короткие MP3/WAV. Если файла нет — сервис молча пропускает звук.

| Файл          | Когда играет                      | Длительность |
|---------------|-----------------------------------|--------------|
| shake.mp3     | Лёд в шейкере (мастерская)        | 1–2 сек      |
| glass_tap.mp3 | Стук бокала о стойку (результат)  | < 1 сек      |
| correct.mp3   | Правильный ответ в квизе          | < 1 сек      |
| success.mp3   | Награда, диплом, бейдж            | 1–2 сек      |
| fail.mp3      | Провал квиза/попытки              | 1 сек        |
| bg_jazz.mp3   | Фон бара (цикл, тихий)            | 20–60 сек    |

Источники без лицензионных ограничений: freesound.org, pixabay.com/sound-effects.
