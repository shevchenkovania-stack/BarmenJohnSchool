# 🎓 Bartender School — Нарратив и Геймификация

> План трансформации школы из "набора уроков" в захватывающее путешествие.

---

## Видение

Студент не "учится". Он **проходит путь** — от новичка за пустой стойкой до мастера с дипломом. Каждый урок — глава книги. Каждый блок — новая территория. Каждый коктейль — награда за мастерство.

---

## Часть 1: Нарратив (Повествование)

### 1.1 Пролог Level 1

**Что:** Вступительный экран перед первым уроком.
**Где:** SchoolHomeScreen → при первом входе в Level 1.
**Эффект:** Погружение с первой секунды.

**Текст (пример):**
> *Ты стоишь за стойкой. Перед тобой — пустой бар. Ни одной бутылки, ни одного бокала. Но ты чувствуешь — здесь что-то будет. Здесь родится мастерство.*
>
> *Меня зовут Джон. Я бармен с 20-летним стажем. И я проведу тебя через всё — от первого вкуса до собственного коктейля.*
>
> *Готов? Тогда начнём с самого начала...*

**Технически:**
- Новый экран `PrologueScreen` или bottom sheet
- Показывается один раз (флаг в ProgressService: `hasSeenPrologue`)
- Аватар Джона + текст + кнопка "Начать путь"

### 1.3 Связки между уроками (Hooks)

**Что:** В конце каждого урока — мостик к следующему.
**Где:** Последний слайд урока / экран завершения квиза.
**Эффект:** "Хочу дальше!"

**Примеры:**

| После урока | Хук |
|-------------|-----|
| A01 (5 вкусов) | "Ты научился распознавать вкусы. Но что если один из них слишком сильный? На следующем уроке ты узнаешь, как укротить кислоту..." |
| A02 (Кислота) | "Кислота под контролем. Но баланс — это не только кислота. Есть ещё один вкус, который всё связывает. Встретимся на следующем уроке..." |
| A04 (Баланс) | "Ты понял формулу баланса. Теперь — инструменты. Без них ты знаешь ЧТО делать, но не знаешь КАК. Блок B ждёт..." |
| B07 (Шейкер) | "Шейк освоен. Но есть коктейли, которые нельзя трясти. Только размешивать. И это — другая философия..." |
| C11 (Негрони) | "Три классики позади. Впереди — экзамен. Не тест — испытание. Ты готов?" |

**Технически:**
- Поле `nextLessonHook` в JSON урока
- Показывается после завершения квиза (в `_showCompletionDialog`)
- Кнопка "Следующий урок →"

### 1.4 Введения в блоки (Block Intros)

**Что:** Отдельный экран перед первым уроком каждого блока.
**Где:** Level1Screen → при первом входе в блок.
**Эффект:** Ощущение "главы книги".

**Тексты:**

**Block A: Пробуждение вкуса**
> *Прежде чем смешивать коктейли, ты должен научиться чувствовать. Твой язык — твой главный инструмент. Не шейкер, не джиггер — язык. Сейчас мы разбудим то, что было с тобой всегда. 4 урока. 5 вкусов. 1 цель — научиться слышать напиток.*

**Block B: Руки и инструменты**
> *Ты чувствуешь вкус. Теперь — руки. Бармен — это ремесло. Здесь нет места "примерно". 30 мл — это 30 мл. Встряхивание — это не тряска. Это точная техника с 200-летней историей. 4 урока — и твои руки будут знать что делать.*

**Block C: Первые коктейли**
> *Всё что ты узнал — вкус, баланс, инструменты — сейчас соединится. Ты создашь три классических коктейля. Каждый — шедевр. Каждый — экзамен сам по себе. А в конце — финальное испытание. 4 урока. 3 коктейля. 1 диплом.*

**Технически:**
- Новый вид контента: `blockIntro` (отдельный JSON или поле в конфиге)
- Показывается при первом открытии блока
- Флаг в ProgressService: `hasSeenBlockIntro_A/B/C`

## Часть 2: Геймификация

### 2.1 Визуальный Skill Tree (Карта пути)

**Что:** Вместо списка уроков — карта пути.
**Где:** Level1Screen (заменяет текущий список).
**Эффект:** Ощущение игры, прогрессии.

**Визуал:**
```
    [A01] ─── [A02] ─── [A03] ─── [A04]
      │         │         │         │
      ▼         ▼         ▼         ▼
    ═══════ БЛОК A ЗАВЕРШЁН ═══════
                     │
    [B05] ─── [B06] ─── [B07] ─── [B08]
      │         │         │         │
      ▼         ▼         ▼         ▼
    ═══════ БЛОК B ЗАВЕРШЁН ═══════
                     │
    [C09] ─── [C10] ─── [C11] ─── [C12 ⚔️]
                                   │
                              🏆 ДИПЛОМ
```

**Состояния узлов:**
- 🔒 Заблокирован — серый, в тумане
- 🟡 Доступен — пульсирует, привлекает внимание
- 🔵 В процессе — синий, прогресс-бар
- 🟢 Пройден (теория) — зелёный
- 🟠 Практика нужна — оранжевый (после теории)
- ✅ Полностью пройден — зелёный + золотая рамка

**Технически:**
- Новый виджет `SkillTreeWidget`
- Использует `CustomPainter` для линий связи
- Анимация пульсации для доступных уроков

### 2.2 Система открытий (Unlock System)

**Что:** Коктейли в Рецептурнике открываются по мере прохождения уроков.
**Где:** CocktailListScreen, CocktailCurriculumService.
**Эффект:** Зарабатываешь знания, не получаешь "всё сразу".

**Логика:**
- Урок C09 пройден → Mojito разблокирован в Рецептурнике
- Урок C10 пройден → Daiquiri разблокирован
- Урок C11 пройден → Negroni разблокирован
- Блок A пройден → открываются техники (Shake, Stir, Build)
- Все блоки → полный доступ к Рецептурнику

**Технически:**
- `ProgressService.unlockedCocktails` уже существует
- Привязать к `diplomaCocktailId` + расширить на все уроки
- В CocktailListViewModel — фильтрация по статусу разблокировки

### 2.3 Ранговая система

**Что:** Визуальный ранг студента, который растёт.
**Где:** SchoolHomeScreen (header), LevelCard.
**Эффект:** "Я расту" — ощущение прогресса.

**Ранги:**

| Ранг | Условие | Иконка |
|------|---------|--------|
| Новичок | Начало пути | 🌱 |
| Стажёр | Block A завершён | 🍃 |
| Бармен | Block B завершён | 🍸 |
| Миксолог | Block C завершён | 🎓 |
| Мастер | Диплом получен | 🏆 |

**Технически:**
- Вычисляемый ранг на основе `ProgressService`
- Отображается в SchoolHomeScreen header
- Анимация при повышении ранга

### 2.4 Система серий (Streak)

**Что:** Множитель XP за ежедневное обучение.
**Где:** SchoolHomeScreen, QuizScreen.
**Эффект:** Привычка возвращаться.

**Логика:**
- 1 день подряд: x1
- 3 дня: x1.5
- 7 дней: x2
- 14 дней: x2.5
- 30 дней: x3

**Технически:**
- `ProgressService.streak` уже существует
- Добавить `lastStudyDate` проверку при `completeLesson`
- Показывать множитель в XP badge

### 2.5 Секретный контент

**Что:** Бонусные рецепты/факты за идеальные результаты.
**Где:** Разблокируются при 100% квиза.
**Эффект:** Любопытство + мотивация.

**Примеры:**
- 100% на A01 → секретный факт о вкусах
- 100% на C09 → авторский рецепт Mojito от Джона
- 100% на экзамене → секретный коктейль "Graduation"

**Технически:**
- `ProgressService.unlockSecret(secretId)` при score == 100
- Отдельная секция "Секреты" в SchoolHomeScreen
