## ЧТО ДОБАВИТЬ (КРИТИЧНО ДЛЯ РЕЛИЗА)

### 1. Показывать картинку коктейля 🖼️
**Приоритет: ВЫСОКИЙ**

**Проблема:** Пользователь видит рецепт БЕЗ фото → не понимает что получится

**Решение:**
```dart
// 1. Добавить в GeneratedCocktail:
final String? imageUrl;
final String? sourceCocktailId;

// 2. CocktailMatcherService передать:
imageUrl: matchedCocktail.source.strDrinkThumb,
sourceCocktailId: matchedCocktail.source.idDrink,

// 3. BuilderResultScreen показать:
if (cocktail.imageUrl != null)
  Image.network(cocktail.imageUrl!)
```

**Время:** ~2 часа

**Файлы:**
- `generated_cocktail.dart` - добавить 2 поля
- `cocktail_matcher_service.dart` - передать данные
- `builder_result_screen.dart` - показать картинку
- `ai_cocktail_screen.dart` - показать картинку

### 2. Индикатор "Можно приготовить" ✅
**Приоритет: ВЫСОКИЙ**

**Проблема:** Пользователь не знает достаточно ли ингредиентов

**Решение:**
```dart
// На форме СРАЗУ показывать:
Row(
  children: [
    Icon(Icons.check_circle, color: green),
    Text('Можно приготовить 3 коктейля'),
  ]
)
// ИЛИ
Row(
  children: [
    Icon(Icons.warning, color: orange),
    Text('Нужно еще 1-2 ингредиента'),
  ]
)
```

**Время:** ~1 час

**Файлы:**
- `builder_form_screen.dart` - добавить индикатор под ингредиентами
- `cocktail_matcher_service.dart` - подсчитать совпадения

### 3. Индикатор загрузки / готовности
**Приоритет: СРЕДНИЙ**
