## ❌ ПРОБЛЕМЫ (ФЕЙК ИЛИ НЕ РАБОТАЕТ)

### 1. "Как настройки повлияли" ← УДАЛИТЬ
**Почему фейк:**
- SettingsInfo приходит из builder_form_screen
- Но matcher НЕ использует эти настройки
- Он просто ищет совпадения ингредиентов
- Текст "Баланс Сухой — меньше сиропа" - ВРАНЬЁ, matcher это не учитывал

**Доказательство:**
```dart
// cocktail_matcher_service.dart - НЕТ references к:
// - balance
// - intensity  
// - sparkling
// - aroma
// - texture
// - bitterness

// Matcher только делает:
for (final ing in cocktail.ingredients) {
  if (userLower.contains(lower)) {
    used.add(ing);
  }
}
```

**Решение:** ❌ УДАЛИТЬ полностью (_SettingsImpactCard)

---

### 2. Ингредиенты с 0 мл ← ИСПРАВИТЬ
**Проблема:**
```dart
// cocktail_matcher_service.dart строка 104
amountMl: _parseMeasureToMl(measures.length > i ? measures[i] : ''),
```

**Почему 0:**
- TheCocktailDB часто отдает пустые measures: `""`
- `_parseMeasureToMl("")` возвращает 0
- Пользователь видит: "Vodka - 0 мл" ← БРЕД

**Пример из API:**
```json
{
  "strIngredient1": "Vodka",
  "strMeasure1": "",  ← ПУСТО!
  "strIngredient2": "Lime juice", 
  "strMeasure2": "30 ml" ← ОК
}
```

**Решение:** 
```dart
// Если measure пустой - показать "по вкусу" или "~30 мл"
amountMl: _parseMeasureToMl(measures.length > i ? measures[i] : ''),

// В IngredientRow:
amount: ing.amountMl > 0 ? '${ing.amountMl} мл' : 'по вкусу',
```

---

### 3. "Факт" и "Секрет бармена" ← ПУСТЫЕ
**Проблема:**
```dart
// cocktail_matcher_service.dart строки 158-159
fact: null,        ← ВСЕГДА null
secret: null,      ← ВСЕГДА null
```

**Почему:**
- Matcher НЕ генерирует контент
- Эти поля ТОЛЬКО для AI mode (которого нет)
- UI показывает пустые блоки если null → они просто не рендерятся

**Решение:** 
- ✅ Оставить как есть (не показываются если null)
- ИЛИ добавить fallback текст для классических рецептов

---

### 4. Metrics Panel (ABV, сахар, калории) ← ПРОВЕРИТЬ
**Проблема:**
```dart
// cocktail_matcher_service.dart
abv: _estimateAbv(cocktailIngredients),  ←估算值
sugarGrams: _estimateSugar(cocktailIngredients),  ←估算值
calories: _estimateCalories(cocktailIngredients),  ←估算值
```

**Почему может быть неточно:**
- Это估算值 на базе ingredient names
- Нет реальных данных о бренде/крепости
- Но хотя бы пытается считать (не фейк)

**Решение:** ✅ ОСТАВИТЬ (лучше чем ничего, честный估算值)

---

### 5. FlavorProfile ← HARDCODED
**Проблема:**
```dart
// cocktail_matcher_service.dart строки 144-150
flavorProfile: const FlavorProfile(
  strength: 5,      ← ВСЕГДА 5
  sweetness: 5,     ← ВСЕГДА 5
  acidity: 5,       ← ВСЕГДА 5
  bitterness: 2,    ← ВСЕГДА 2
  sparkling: false, ← ВСЕГДА false
),
```

**Почему фейк:**
- Одинаково для ВСЕХ коктейлей
- Mojito (сладкий) = Margarita (кислый) = Old Fashioned (крепкий)
- Это ВРАНЬЁ

**Решение:** ❌ УДАЛИТЬ ИЛИ рассчитать реальный профиль

### 6. MixologyExplanation ← GENERIC TEXT
**Проблема:**
```dart
// cocktail_matcher_service.dart строки 151-156

  balance: 'Классический баланс',     ← ОДИНАКОВО для всех
  aroma: 'Характерный аромат коктейля', ← ОДИНАКОВО для всех
  overall: 'Проверенный временем рецепт', ← ОДИНАКОВО для всех
),
```

**Почему фейк:**
- Generic текст для ВСЕХ коктейлей
- Не объясняет реальный баланс
- Пользователь не дурак, заметит

**Решение:** ❌ УДАЛИТЬ ИЛИ сделать dynamic
