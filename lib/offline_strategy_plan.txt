# OFFLINE СТРАТЕГИЯ - КОНСТРУКТОР КОКТЕЙЛЕЙ

## ТЕКУЩЕЕ СОСТОЯНИЕ

### Что ЕСТЬ:
✅ CocktailRepository.preloadAll() - загружает A-Z в память при старте
✅ In-memory кэш (_letterCache) - быстрый доступ пока приложение открыто
❌ НЕТ persistent storage - при закрытии приложения кэш теряется
❌ НЕТ offline fallback - без интернета конструктор НЕ работает

### Проблема:
```
User открывает приложение без интернета
↓
preloadAll() → FAIL (нет сети)
↓
_cocktailRepo.getAllCached() → [] (пусто)
↓
Matcher: "База коктейлей не загружена"
↓
User: "⚠️ Проверьте интернет" ← КОНСТРУКТОР НЕ РАБОТАЕТ!
```

## ПЛАН РЕАЛИЗАЦИИ

### ЭТАП 1: Добавить Hive для cocktail cache (3 часа)

**Файл:** `lib/core/services/cocktail_cache_service.dart`

```dart
import 'package:hive/hive.dart';
import 'package:coin/core/models/cocktail.dart';

class CocktailCacheService {
  static const String _boxName = 'cocktails_cache';
  
  /// Сохранить все коктейли в Hive
  Future<void> saveAll(List<Cocktail> cocktails) async {
    final box = await Hive.openBox(_boxName);
    await box.clear();
    
    for (final cocktail in cocktails) {
      await box.put(cocktail.idDrink, cocktail.toJson());
    }
    
    await box.put('last_updated', DateTime.now().toIso8601String());
    print('💾 Saved ${cocktails.length} cocktails to Hive');
  }
  
  /// Загрузить из Hive (offline)
  List<Cocktail> loadAll() {
    final box = Hive.openBox(_boxName);
    final cocktails = <Cocktail>[];
    
    for (final key in box.keys) {
      if (key == 'last_updated') continue;
      
      final data = box.get(key) as Map<String, dynamic>;
      cocktails.add(Cocktail.fromJson(data));
    }
    
    print('📂 Loaded ${cocktails.length} cocktails from Hive');
    return cocktails;
  }
  
  /// Проверить когда было последнее обновление
  DateTime? getLastUpdated() {
    final box = Hive.openBox(_boxName);
    final iso = box.get('last_updated') as String?;
    return iso != null ? DateTime.parse(iso) : null;
  }
  
  /// Кэш старше 7 дней = stale
  bool isStale() {
    final last = getLastUpdated();
    if (last == null) return true;
    
    return DateTime.now().difference(last) > Duration(days: 7);
  }
}
```

### ЭТАП 2: Изменить CocktailRepository (2 часа)

**Файл:** `lib/core/repositories/cocktail_repository.dart`

```dart
class CocktailRepository {
  final _api = CocktailApi();
  final _cache = CocktailCacheService();  ← НОВОЕ
  final Map<String, List<Cocktail>> _letterCache = {};
  List<Cocktail>? _allCocktails;  ← НОВОЕ

  /// Загрузить все коктейли (API → Cache → Memory)
  Future<List<Cocktail>> getAll() async {
    // 1. Попробовать из memory
    if (_allCocktails != null) {
      return _allCocktails!;
    }
    
    // 2. Попробовать из Hive (offline)
    final cached = _cache.loadAll();
    if (cached.isNotEmpty) {
      _allCocktails = cached;
      print('✅ Loaded from Hive cache (offline)');
      
      // Если кэш старый - обновить в фоне
      if (_cache.isStale()) {
        _refreshInBackground();
      }
      
      return cached;
    }
    
    // 3. Загрузить из API (нужен интернет)
    try {
      await preloadAll();
      _allCocktails = getAllCached();
      
      // Сохранить в Hive для offline
      await _cache.saveAll(_allCocktails!);
      print('✅ Loaded from API and cached to Hive');
      
      return _allCocktails!;
    } catch (e) {
      throw Exception('Нет интернета и нет локальной базы. Скачайте базу при первом запуске.');
    }
  }

  /// Обновить кэш в фоне
  Future<void> _refreshInBackground() async {
    try {
      await preloadAll();
      final all = getAllCached();
      await _cache.saveAll(all);
      print('✅ Cache refreshed in background');
    } catch (e) {
      print('⚠️ Background refresh failed: $e');
    }
  }

  /// Проверить доступен ли offline mode
  bool get isOfflineAvailable {
    return _cache.loadAll().isNotEmpty;
  }
}
```

class AiEnhancerService {
  Future<GeneratedCocktail> enhance(GeneratedCocktail base) async {
    // 1. Проверить интернет
    final hasInternet = await _checkInternet();
    
    if (!hasInternet) {
      print('⚠️ No internet - AI Enhancer skipped');
      return base;  ← Вернуть без улучшений (НЕ ошибка!)
    }
    
    // 2. Проверить API ключ
    if (apiKey == null) {
      return base;  ← Вернуть без улучшений
    }
    
    // 3. Вызвать AI
    try {
      final enhanced = await _callOpenAI(base);
      return enhanced;
    } catch (e) {
      print('⚠️ AI Enhancer failed: $e');
      return base;  ← Fallback к базовому рецепту
    }
  }
}
