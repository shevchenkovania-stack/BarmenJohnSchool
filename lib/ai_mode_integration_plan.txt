# AI РЕЖИМ В КОНСТРУКТОРЕ - ПЛАН ИНТЕГРАЦИИ

## ТЕКУЩЕЕ СОСТОЯНИЕ

### AI Recipe Guide (РАБОТАЕТ):
- 📍 Где: cocktail_detail_screen.dart → кнопка "AI Рецепт"
- 🔧 Service: RecipeAIService.expand()
- 📦 Model: DetailedRecipe (полный рецепт от AI)
- 🎯 Flow: 
  1. User открывает коктейль из базы
  2. Жмет "AI Рецепт"
  3. RecipeAIService вызывает OpenAI API
  4. Возвращает DetailedRecipe (пошагово, советы, история, техники)
  5. Показывает в AiRecipeViewer

### Cocktail Builder (ТОЛЬКО rule-based):
- 📍 Где: builder_form_screen.dart → кнопка "Создать коктейль"
- 🔧 Service: CocktailMatcherService.match()
- 📦 Model: GeneratedCocktail (простой рецепт)
- 🎯 Flow:
  1. User выбирает ингредиенты
  2. Matcher ищет совпадения в базе
  3. Возвращает GeneratedCocktail (без AI)
  4. Показывает в ResultScreen

```dart

  cocktail = await enhancer.enhance(cocktail);

-- */
```

**AI Enhancer должен:**
1. Взять GeneratedCocktail от matcher
2. Отправить в OpenAI для улучшения
3. Добавить: pro tips, facts, secrets, garnish, serving suggestions
4. Вернуть улучшенный GeneratedCocktail

**НО:** AiEnhancerService НЕ СУЩЕСТВУЕТ! (только ai_enhancer_service.dart файл пустой или старый)

## ПЛАН ИНТЕГРАЦИИ (3 ЭТАПА)

### ЭТАП 1: Создать AiEnhancerService (2 часа)
**Файл:** `lib/features/cocktail_builder/services/ai_enhancer_service.dart`

**Функция:**
```dart
class AiEnhancerService {
  final String apiKey;
  
  Future<GeneratedCocktail> enhance(GeneratedCocktail base) async {
    // 1. Build prompt
    final prompt = '''
      Enhance this cocktail recipe:
      Name: ${base.name}
      Ingredients: ${base.ingredients}
      
      Add:
      - proTip (professional advice)
      - fact (interesting history)
      - secret (bartender trick)
      - garnish (decoration)
      - serving suggestion
      - flavor profile (strength, sweetness, acidity, bitterness)
      
      Return JSON.
    ''';
    
    // 2. Call OpenAI
    final response = await callOpenAI(prompt);
    
    // 3. Parse and merge
    return base.copyWith(
      proTip: response['proTip'],
      fact: response['fact'],
      secret: response['secret'],
      garnish: response['garnish'],
      serving: response['serving'],
      flavorProfile: FlavorProfile.fromJson(response['flavorProfile']),
    );
  }
}
```

## ВАЖНО

**AI Enhancer ≠ AI Recipe Guide**

- **AI Recipe Guide** (существует): 
  - Для ГОТОВОГО коктейля из базы
  - Возвращает DetailedRecipe (очень подробный)
  - Используется в cocktail_detail_screen

- **AI Enhancer** (надо создать):
  - Для cocktail builder
  - Улучшает GeneratedCocktail
  - Добавляет tips/facts/secrets
  - Быстрее (меньше токенов)

**НЕЛЬЗЯ использовать RecipeAIService в builder** потому что:
- Он возвращает DetailedRecipe, не GeneratedCocktail
- Очень дорогой (1500 токенов)
- Медленный (ждет полный рецепт)
- Не совместим с ResultScreen

**НУЖНО создать отдельный AiEnhancerService** который:
- Работает с GeneratedCocktail
- Дешевый (500 токенов)
- Быстрый
- Совместим с ResultScreen
