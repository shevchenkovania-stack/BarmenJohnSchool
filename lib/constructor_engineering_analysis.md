## ❌ КРИТИЧЕСКИЕ ПРОБЛЕМЫ (БЛОКЕРЫ)

### 1. Индикатор "Можно приготовить X коктейлей" - ФЕЙК!

**Файл:** `builder_form_screen.dart` строки 338-347

```dart
int _calculateMatchCount() {
  if (viewModel.selectedIngredients.length < 2) return 0;
  // Простая логика - можно улучшить подключив matcher
  // Пока показываем примерное количество
  final count = viewModel.selectedIngredients.length;
  if (count >= 5) return 3;  // ❌ ХАРДКОД!
  if (count >= 4) return 2;  // ❌ ХАРДКОД!
  if (count >= 3) return 1;  // ❌ ХАРДКОД!
  return 0;
}
```

**Проблема:**
- ❌ ВРЁТ пользователю!
- ❌ Не вызывает реальный matcher
- ❌ "5 ингредиентов = 3 коктейля" - это НЕПРАВДА

**Решение:**
```dart
int _calculateMatchCount() {
  return viewModel.matchedCocktails.length; // ✅ РЕАЛЬНОЕ количество
}
```

### 2. Balance/Intensity слайдеры - РАБОТАЮТ С AI ✅

**Файл:** `cocktail_builder_viewmodel.dart` строки 41-42

```dart
int _balance = 5; // 0-10: Сухой ↔ Сладкий
int _intensity = 5; // 0-10: Лёгкий ↔ Крепкий
```

**Статус:** ✅ ИСПРАВЛЕНО!

**Как работают:**
- Влияют на AI промпт (ai_enhancer_service.dart)
- Balance: сухой ↔ сладкий → AI подбирает garnish и flavor profile
- Intensity: лёгкий ↔ крепкий → AI корректирует strength в flavorProfile

**Пример промпта:**
```
USER PREFERENCES:
User prefers DRY/SOUR cocktails (less sweet, more acidic)
User prefers STRONG cocktails (high alcohol, intense)
```

**Ограничение:**
- ⚠️ Работают ТОЛЬКО с AI mode
- ⚠️ Без AI = базовый matching (слайдеры не влияют)

**Решение:**
- Добавить tooltip: "Настройки влияют на AI рекомендации"
- Или показывать слайдеры ТОЛЬКО когда AI enabled

## ⚠️ СРЕДНИЕ ПРОБЛЕМЫ

### 4. Suggested Replacements - ПУСТЫЕ

**Файл:** `cocktail_matcher_service.dart` строка 133

```dart
suggestedReplacements: _buildReplacements(match),
```

**Проблема:**
- `_buildReplacements()` возвращает `{}` (пустую map)
- User видит "Не хватает: мяты" но НЕ видит чем заменить

**Решение:**
```dart
Map<String, String> _buildReplacements(MatchedCocktail match) {
  const replacements = {
    'mint': 'базилик или мелисса',
    'vodka': 'джин или белый ром',
    'lime juice': 'лимонный сок',
    // ... добавить 20+ замен
  };
  
  return {
    for (final missing in match.missingIngredients)
      if (replacements.containsKey(missing.toLowerCase()))
        missing: replacements[missing.toLowerCase()]!
  };
}
```
