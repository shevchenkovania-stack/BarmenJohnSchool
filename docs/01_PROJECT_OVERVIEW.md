# Project Overview

## Что это

`coin` - Flutter-приложение про коктейли, которое сейчас переориентируется в продукт **"Школа бармена Джона"**.

Первоначально в проекте было несколько направлений:

- список коктейлей;
- конструктор коктейлей;
- AI-рецепты;
- бар-менеджер;
- калькулятор себестоимости;
- меню/QR/guest mode;
- кофейные экраны.

Текущий продуктовый фокус: **мобильная школа бармена**, где пользователь учится, тренируется в Мастерской, закрепляет классику и получает диплом.

## Главная идея

Приложение должно ощущаться не как справочник и не как набор несвязанных экранов, а как курс:

1. Пользователь входит в школу.
2. Бармен Джон объясняет путь.
3. Уроки дают понятную теорию.
4. Мастерская превращает теорию в практику.
5. Квизы и задания проверяют понимание.
6. Диплом мотивирует закончить курс.

## Первый релиз

Для первого релиза основной продукт:

- Школа бармена Джона.
- Level 1 как основной законченный курс.
- Мастерская как практика, связанная с уроками.
- Библиотека коктейлей как справочник.
- Диплом, видимый заранее, но заблокированный до выполнения условий.

Второстепенные или скрытые направления:

- Coffee List - не относится к школе бармена, не должен быть виден в основном сценарии.
- Bar Manager, Cost Calculator, Menu Builder, QR Menu, Guest Mode - полезны позже, но для первого релиза могут размывать позиционирование.
- AI Recipes - не должен быть центральной фичей первой версии, если нет надежной автономной стратегии.

## Текущая главная навигация

Файл: `lib/shell/main_shell.dart`

Сейчас нижняя навигация состоит из трех вкладок:

- `Школа` -> `HomeScreen`
- `Рецепты` -> `CocktailListScreen`
- `Мастерская` -> `WorkshopScreen`

Это соответствует текущему направлению: школа первая, рецепты вторые, практика третья.

## Что пользователь должен понять за первые 30 секунд

- Это школа бармена, а не просто список напитков.
- У него есть наставник - Бармен Джон.
- Есть путь обучения, прогресс и диплом.
- Практика нужна не отдельно, а для прохождения школы.
- Рецепты - это библиотека знаний, а не главный экран.

## Название и образ

Рабочая идея бренда: **Школа бармена Джона** / **Бармен Джон**.

Джон - не декоративная картинка. Он выполняет роль наставника:

- объясняет смысл урока;
- предупреждает про типичные ошибки;
- связывает теорию с реальной стойкой;
- ведет ученика к практике и экзамену.

## Критерий качества

Приложение не должно выглядеть как "фейковая школа". Контент и UI должны создавать ощущение, что опытный бармен реально передает базу:

- меньше случайных фич;
- больше причинно-следственной связи;
- каждый урок должен иметь практический смысл;
- каждый термин должен быть объяснен по делу;
- Мастерская должна быть нужна для прогресса.
