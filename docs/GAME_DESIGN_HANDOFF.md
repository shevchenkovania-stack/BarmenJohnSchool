# Школа бармена Джона — как устроена игра

Документ для внешнего геймдизайнера. Всё ниже — **факт из кода и данных**, а не
идея. Номера строк указаны, чтобы можно было проверить. Где система недоделана
или противоречит сама себе — это помечено отдельно.

Обновлять этот файл нужно в том же коммите, что и изменение механик.

---

## 1. Что это за продукт

Мобильное приложение (Flutter, Android в первую очередь) — **школа бармена**,
где наставник Джон ведёт ученика от нуля до диплома. Офлайн-первый: обязательная
часть работает без сети, все проверки знаний — rule-based (никакого AI в
проверке).

Рамки, которые нельзя нарушать (из `AGENTS.md`):

- продукт называется «Школа бармена Джона», Джон — сценарный наставник, а не чат;
- обязательное обучение работает offline и по правилам;
- проваленный квиз **не** завершает урок;
- XP и награды **идемпотентны** (повтор не даёт награду дважды);
- Level 2 открывается только после честного диплома Level 1;
- карточка с тематическим изображением не содержит Джона; Джон появляется на
  открытой карточке и внутри урока.

## 2. Основной цикл

```
Главная
  └─ Level 1 → карточка блока (A/B/C)
        └─ открытая карточка урока (Джон говорит)
              └─ УРОК = 4–10 слайдов (PageView)
                    ├─ «Далее» между слайдами
                    └─ на последнем слайде «К тесту»
              └─ ГЕЙТ ТЕРМИНОВ (отдельный квиз на словарь)
              └─ ОСНОВНОЙ КВИЗ (порог прохождения)
                    ├─ провал → урок НЕ завершён, можно повторить
                    └─ проход → урок completed: XP + монеты + серия дней
              └─ МАСТЕРСКАЯ (практика: собрать коктейль, 0–3 звезды)
                    └─ 2+ звезды → коктейль открывается ученику

Параллельно: Мудрость (покупается за монеты), Дегустация (1 раунд в день),
Диплом (после всех требований Level 1).
```

Точки в коде: цикл урока — `lesson_screen.dart:46-106`, квиз и начисление —
`quiz_screen.dart:300-338`, практика — `practice_flow_screen.dart:108-146`.

## 3. Урок: слайды

Урок — лента слайдов (`PageView`) с полосой прогресса. Слайд — запись с полями
`type, title, content, bulletPoints, mentorNote, imageUrl, choices`
(`domain/entities/lesson.dart:98-140`).

Типы слайдов (`SlideType`, `lesson.dart:185-199`):

| Тип | Что это | Интерактив |
|---|---|---|
| `theory` | текст | нет |
| `toolVisual` | разбор инструмента | нет |
| `practice` | инструкция к упражнению | нет |
| `barTip` | лайфхак из практики | нет |
| `checklist` | чек-лист перед сменой | нет |
| `interactive` | калибровка (кислота) | слайдеры |
| `balanceTrainer` | тренажёр баланса | слайдеры |
| `choice` | сцена с выбором одного хода | кнопки |
| `failure` | «Моя ошибка» — история Джона | нет |
| `quote` | золотое правило + автор | нет |
| `observation` | «барменский радар» | нет |
| `silence` | пауза-вдох без задания | нет |
| `termAnimation` | термин | нет |

Важно: **слайд не оценивается**. Интерактивные слайды собирают ответ, но
результат не входит в прогресс урока. Оценка происходит только в квизе.

Навигация: «Назад» / «Далее», на последнем слайде кнопка меняется на «К тесту»
(`lesson_screen.dart:1740-1841`).

## 4. Квиз

### 4.1 Типы вопросов

Из `data/content/quizzes_*.json`: `singleChoice`, `multipleChoice`, `trueFalse`,
`matching`, `sequence`, `slider`.

### 4.2 Двойной вход

Перед основным квизом стоит **гейт терминов** — отдельный экран
`TermQuizScreen` (`lesson_screen.dart:67-106`). Он проверяет термины урока и
может открыться **повторно**, если за один проход ученик не выучил все термины.

```
слайды → [гейт терминов] → [гейт терминов, если остались невыученные] → основной квиз
```

### 4.3 Прохождение

- порог — число верных ответов из данных квиза, процент школы — фолбэк;
- провал → урок не завершается, прогресс не теряется;
- повторный проход по уже завершённому уроку не даёт XP второй раз
  (`completeLesson` проверяет `wasCompleted`, `progress_service.dart:337-344`).

### 4.4 Что начисляется за урок

Из `quiz_screen.dart:310-338`:

- XP: `xpPerLesson` = 50 (только при проходе);
- монеты: `coinsPerLesson` = 50 + бонус за процент (100%→75, 90%→50, 70%→25);
- ежедневные задания: «пройди урок» +50 монет, «квиз на 80%+» +30 монет.

Награда показывается **внутри** экрана результата квиза, строкой `+50 XP`.

## 5. Практика (Мастерская)

Мастерская открывается после первого завершённого урока
(`shell/main_shell.dart:54-56`).

Задание (`data/practice_challenges.dart:18-47`):

```
correctIngredients   — правильные ингредиенты
wrongOptions         — ловушки
correctMethod        — метод (shake / stir / build)
proportions          — целевые пропорции по ингредиентам
assembly             — правильный порядок сборки (может быть пустым)
```

Оценка → 0–3 звезды. Таймер 60 секунд на шаги 1–3, бонус за время — если
осталось ≥ 20 секунд.

Начисление (`progress_service.dart:665-705`):

- XP: **только за новые звёзды** (`improvedStars * 10`) + 10 за первый бонус
  времени — так исключён фарм XP повторами;
- монеты: 25 за каждую новую звезду;
- 2+ звезды → коктейль добавляется в `unlockedCocktails` и урок помечается
  как прошедший практику;
- после попытки проверяются бейджи (`checkAndAwardBadges`).

## 6. Экономика и прогресс

Хранилище: `SharedPreferences`, один JSON-объект `bartender_school_progress`
(`domain/entities/progress.dart:30-74`). Поля:

```
totalXP            — суммарный опыт (для ранга)
coins              — тратятся на Мудрость
streak             — дни подряд
lessonStatuses     — lessonId → locked | available | inProgress | completed
usedQuestionIds    — какие вопросы уже задавались
unlockedCocktails  — открытые коктейли
achievements       — открытые бейджи
purchasedWisdom    — купленные фрагменты Мудрости
lastStudyDate      — для серии дней
```

Числа (`data/school_config.dart:15-39`):

| Параметр | Значение |
|---|---|
| XP за урок | 50 |
| XP за квиз | 25 |
| XP за звезду практики | 10 |
| Монеты за урок | 50 |
| Бонус монет за квиз | 25 / 50 / 75 (70 / 90 / 100 %) |
| Монеты за звезду практики | 25 |
| Уроков в Level 1 / Level 2 | 13 / 12 |
| Фрагментов Мудрости | 7 |

Награды за блок (`data/block_rewards.dart`): блок A — ранг «Стажёр»
(+100 XP, +100 монет), B — «Бармен» (+150/+150), C — «Миксолог» (+200/+200).
Начисляется один раз (`hasClaimedBlockReward`).

Серия дней (`progress_service.dart:405-426`): тот же день — не растёт, +1 день —
растёт, пропуск — сбрасывается.

- 8 состояний-изображений: обычный, учит, практика, экзамен, празднует, hero,

## 10. Что здесь сломано или спорно (для обсуждения)

Это **не** мнение — это расхождения, найденные в коде и документации.

### 10.1 Двойной квиз подряд

`lesson_screen.dart:79-96`: гейт терминов открывается перед основным квизом и
может открыться повторно. Итог для ученика: слайды → тест → тест. Ученик
не получает ни одного «финиша» между проверками.

### 10.2 Нет события «урок пройден»

`completeLesson` только меняет статус и пишет цифры. Экрана/сцены «урок
пройден» нет: после квиза возврат в список. Награда (XP) живёт строкой внутри
результата квиза.

### 10.3 Бейджи не доходят до игрока

`checkAndAwardBadges()` вызывается только из `recordPracticeAttempt`
(`progress_service.dart:704`) — то есть **только после практики**. За уроки,
квизы, серию дней и серебро на экзамене бейджи не проверяются. Требование
проекта «достижение открывается автоматически и показывает уведомление в UI»
не выполнено: уведомления нет вовсе.

### 10.4 `_unlockNextLesson` — пустая заглушка

`progress_service.dart:428-432`: метод-пустышка с комментарием. Разблокировка
работает только через сравнение `unlockCondition` со статусом. Значит
«ветвистых» разблокировок (одно задание → два урока) система не умеет.

### 10.5 Прогресс урока считает нагрузку, а не близость к цели

`lesson_screen.dart:594-635`: `Слайд 3 из 12` + `25%`. На последнем слайде
прогресс = `(n-1)/n`, то есть **никогда не доходит до 100%** перед квизом.
Отдельно: `progress = currentSlide / totalSlides`, поэтому первый слайд
показывает `0%`.

### 10.6 Практика — единственное место с ощутимым риском

Здесь есть таймер, звёзды, бонус за время, звук (`BarSoundService`), и XP за
новые звёзды. Это единственная подсистема, где есть напряжение и потеря.

### 10.7 Мудрость покупается за монеты, которые даёт учёба

Учёба → монеты → контент. Это единственный «магазин» в продукте, и он
внутри учебного контента. Стоит подтвердить, что это не ощущается как
искусственная стена.

### 10.8 Пасмурность

Все 7 комнат (`john_school_visuals.dart:37-103`) — тёмное дерево и приглушённое
золото. Ни одна механика не использует яркий акцент для «события»: успех,
провал и обычная теория живут в одном тоне.

## 11. Вопросы геймдизайнеру

1. Ритм «слайды → тест → тест» надо склеить в один квиз или это осознанное
   «два шага повторения»?
2. Нужен ли отдельный экран-финал урока как обязательный элемент петли?
3. Где должна жить награда: в результат квиза или в отдельное событие?
4. Практика — должен ли таймер быть везде или это спецрежим «на скорость»?
5. Достаточно ли 3 звёзд как единственной шкалы мастерства, или нужна
   долгоживущая шкала (ранг, коллекция, серия)?
6. Монеты за учёбу и покупка контента — оставляем или разводим валюты?
7. Как должно ощущаться «Level 2 закрыт»: как цель или как запрет?
