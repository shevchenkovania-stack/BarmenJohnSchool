# Lesson Cards and Barista John UX

Этот документ фиксирует текущий стандарт карточек и роль Бармена Джона.

Подробный исходный документ:

- `LESSON_CARD_DESIGN_STANDARD.md`

## Главная идея карточек

У карточки урока есть две разные поверхности:

1. Карточка в сетке уровня.
2. Открытая карточка после клика.

Они не должны дублировать друг друга.

## Карточка в сетке уровня

Файл:

- `lib/features/bartender_school/presentation/widgets/lesson_card.dart`

Задача лицевой карточки:

- быстро показать тему урока;
- показать номер урока;
- показать статус;
- показать название;
- не перегружать текстом.

Правило:

- если есть тематическая картинка урока, на лицевой стороне нет Джона и нет речи Джона;
- если тематической картинки нет, можно использовать старый fallback с маленьким Джоном.

Для Level 1 блоки B и C теперь считаются отдельными визуальными ступенями:

- у них свой цветовой мир карточек;
- у них разные варианты Джона по урокам, чтобы карточки не повторялись;
- они должны ощущаться как переход от базы к мастерству, а не как повтор одного и того же экрана.

## Открытая карточка

Файл:

- `lib/features/bartender_school/presentation/screens/flip_card_screen.dart`

Сейчас `_buildFront()` всегда ведет в `_buildJohnStoryFront()`.

Открытая карточка должна:

- показывать Джона;
- показывать название урока;
- показывать `historicalStory`;
- показывать `shortDescription`;
- показывать время и количество терминов;
- держать кнопку `Начать урок` видимой без скролла;
- давать переход `К ключевым точкам` на обратную сторону flip-card.

Важно:

- Кнопка `Начать урок` не должна быть внутри скролла.
- Скролл допустим только в средней области с историей/описанием.
- На открытой карточке не нужно одновременно показывать тематическую картинку и Джона.

## Обратная сторона карточки

Обратная сторона остается для подробностей:

- расширенное описание;
- ключевые точки;
- дополнительные сведения.

Она не должна заменять полноценный урок, а должна помогать понять, что будет внутри.

## Бармен Джон

Файлы образа:

- `images/barista_john_teach.png`
- `images/barista_john_practice.png`
- `images/barista_john_exam.png`
- `images/barista_john_hero.png`
- `images/barista_john_celebrate.png`
- `images/barista_john_logo.png`

Выбор аватара по блоку:

- Block A -> `barista_john_teach.png`
- Block B -> набор вариаций `teach / hero / practice / celebrate`
- Block C -> набор вариаций `exam / teach / hero / celebrate`

Для B и C допускается ротация аватаров по конкретным урокам, чтобы визуально поддержать ощущение нового этапа обучения.

## Характер Джона

Джон должен ощущаться как опытный наставник:

- спокойный;
- прямой;
- немного суровый, но не токсичный;
- говорит как человек, который стоял за стойкой;
- объясняет, зачем навык нужен в реальной работе.

Он не должен быть:

- рекламным маскотом;
- декоративной иконкой без смысла;
- слишком болтливым;
- заменой учебного контента.

## Где Джон уже используется

- главный экран школы;
- пролог Level 1;
- briefing блоков;
- открытые карточки уроков;
- уроки и mentor blocks;
- квизы и next lesson hook;
- Мастерская;
- диплом/сертификат.

## Что нельзя ломать

- Не добавлять Джона на лицевую карточку поверх тематической картинки.
- Не делать открытую карточку смесью "картинка + Джон + длинный текст".
- Не прятать кнопку `Начать урок` под скроллом.
- Не удалять `historicalStory` из учебного входа.
- Не превращать Джона в случайный tooltip.
