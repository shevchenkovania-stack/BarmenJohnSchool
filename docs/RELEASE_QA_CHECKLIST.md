# Чек-лист приёмки перед первым релизом (v1.0.0)

> Назначение: пройти по приложению глазами пользователя и убедиться, что
> первый релиз можно отдавать в Google Play. Документ — рабочий: пункты
> отмечаются по мере прохода, найденные дефекты уходят в
> [`TODO_RELEASE_PLAN.md`](TODO_RELEASE_PLAN.md).
>
> Сверено с кодом: 2026-11-07. Стек: Flutter 3.x, `provider`, Hive,
> `shared_preferences`, `google_fonts` (runtime-загрузка), `shelf` (QR-меню),
> `flutter_secure_storage` (ключ OpenAI).

## Как пользоваться

1. Проходить сверху вниз: сначала **блокеры**, потом экраны, потом сквозные сценарии.
2. Каждый экран проверять в **двух** конфигурациях минимум:
   - телефон 360×640, системный шрифт 1.0;
   - телефон 360×640, системный шрифт 1.3 (Настройки → Размер шрифта).
3. Ни один пункт не считается пройденным, если в консоли появился
   `RenderFlex overflowed`, `setState() called after dispose`, красный экран
   или пустой/бесконечный спиннер.
4. Для каждого экрана фиксировать: **вход → действие → ожидаемое → фактическое**.

Обозначения: `[ ]` — не проверено, `[x]` — ок, `[!]` — дефект (с номером
задачи в `TODO_RELEASE_PLAN.md`).

## Часть 0. Блокеры: без них сборку в магазин не выпускаем

Проверяется на коде / терминале, не «на глаз».

- [ ] **applicationId** — сейчас `com.example.coin` (`android/app/build.gradle`).
      Google Play не принимает `com.example.*`. Нужен реальный id
      (например `md.shevchenco.barmenjohn`) — без него релиз невозможен.
- [ ] **Release-подпись** — сейчас `buildTypes.release` использует
      `signingConfigs.debug`. Нужен keystore + `key.properties` (не в git).
- [ ] **Секреты** — ключ OpenAI не в git: `.env` в `.gitignore`,
      `git grep -nI "sk-"` пустой, ключ отозван/перевыпущен.
- [ ] **Ключ OpenAI у пользователя** — хранится в `flutter_secure_storage`
      (`ApiKeyService`). Проверить: без ключа AI-режим деградирует в
      rule-based, а не падает.
- [ ] **`flutter build appbundle --release`** собирается с нуля
      (`flutter clean` → `pub get` → build) без ошибок.
- [ ] **Иконка и название** — `flutter_launcher_icons` применён,
      `android:label` = «Бармен Джон», иконка не мыльная на 48/72/96/144/192.
- [ ] **Нет сети при старте** — приложение запускается в авиарежиме и
      показывает школу (Level 1 полностью офлайновый).
- [ ] **`flutter analyze`** — новых error/warning нет (сейчас в проекте
      накопленный legacy-долг `info`, он не блокирует).
- [ ] **Тесты** — `flutter test test/bartender_school/level1
      test/bartender_school/level2` зелёные.
- [ ] **Шрифты без интернета** — `google_fonts` по умолчанию тянет шрифты из
      сети. Проверить первый запуск в авиарежиме: имена/цитаты не должны
      «прыгать» с системного шрифта на фирменный (либо зашить шрифты
      ассетами).

## Часть 1. Экраны: элементы, кнопки, тексты

### 1.1 Онбординг / первый запуск

Элементы: `MainShell` → `HomeScreen`, при первом входе в Level 1 —
`StudentNameDialog`, пролог Джона, брифинг блока A.

- [ ] Первый запуск без данных: нет пустых карточек, нет «0/0», нет красных
      ошибок.
- [ ] Диалог имени: пустое имя → кнопка неактивна; пробелы обрезаются;
      длинное имя (30+ символов) не ломает вёрстку; отмена → остаёмся на главной.
- [ ] Диалог имени больше не появляется после сохранения (перезапуск приложения).
- [ ] Пролог Джона: текст читается, кнопка «Начать обучение» закрывает окно,
      после неё открывается брифинг, а не пустой экран.
- [ ] Брифинг блока: «Понятно» закрывает, повторный вход в блок пролог не
      показывает снова.
- [ ] Системное «Назад» в диалоге не выкидывает из приложения.

### 1.2 Главный экран (таб «Школа»)

Элементы: шапка с логотипом, карточка «Level 1: Базовый курс», быстрые
действия «Словарь» и «Диплом», иконка настроек, нижняя навигация.

- [ ] Шапка: «ШКОЛА БАРМЕНА ДЖОНА» + подзаголовок в одну-две строки, без
      обрезания на 320 px.
- [ ] Кнопка настроек (шестерёнка) — открывает `SettingsScreen`, возврат работает.
- [ ] Карточка Level 1: тап → диалог имени (первый раз) → Level 1.
      После прохождения имя не спрашивается.
- [ ] «Словарь» → `GlossaryScreen`; «Диплом» → `CertificatesScreen`.
- [ ] Нижняя навигация: «Школа» / «Мудрость» / «Мастерская».
      Мастерская до первого урока показывает замок и снекбар
      «🔒 Пройди первый урок…»; после урока A_01 — открывается.
- [ ] Переключение табов не сбрасывает скролл и данные (IndexedStack).
- [ ] Тап по активному табу ничего не ломает.

### 1.3 Level 1 — сетка уроков (`Level1Screen`)

Элементы: прогресс уровня, карточки уроков (`lesson_card.dart`), замки,
звёзды, печать «теория пройдена», практика.

- [ ] Все 13 карточек на месте, картинки уроков загружаются (нет серых
      прямоугольников / иконки битого изображения).
- [ ] Заблокированный урок: замок, тап показывает понятное сообщение, урок не
      открывается.
- [ ] Открытый урок: карточка → `FlipCardScreen` (лицевая сторона **без**
      Джона, с тематическим изображением).
- [ ] Переворот карточки: оборот содержит Джона и историю; текст не
      переполняется; кнопка «Начать урок» ведёт в `LessonScreen`.
- [ ] Статусы отображаются корректно после прохождения: теория → звёзды
      квиза → практика. Нет «теория пройдена», но «0/3 звёзд» при честном
      прохождении.
- [ ] Прогресс уровня (`X из 13`) совпадает с числом завершённых уроков.
- [ ] Скролл до последнего урока на 360×640, без «залипания» нижней кнопки.

### 1.4 Урок (`LessonScreen`) — все типы слайдов

Элементы: индикатор «Слайд N из M», карточка ментора (Джон), тело слайда,
кнопки «Назад» / «Далее» / «К тесту», иконка словарика, нижняя панель.

Слайды (`SlideType`): `theory`, `termAnimation`, `barTip`, `checklist`,
`toolVisual`, `balanceTrainer`, `interactive`, `practice`, `failure`, `quote`
+ тренажёры: кислотность, сладость, горечь, станция, джиггер, шейкер,
дильюшн, сборка коктейля.

- [ ] Все 13 уроков Level 1 пройдены до конца свайпом кнопок (без свайпа
      пальцем — он отключён намеренно).
- [ ] Прогресс-бар и «Слайд N из M» совпадают на каждом шаге.
- [ ] «Назад» на первом слайде отсутствует; на последнем — «К тесту» с
      иконкой кубка.
- [ ] Тексты: нет опечаток, нет обрывов посреди слова, нет «undefined»/`null`,
      эмодзи рендерятся (не квадраты).
- [ ] Цвета: текст читается на панели комнаты **во всех** уроках (A–F, W).
      Нет синих/фиолетовых элементов, выпадающих из палитры.
- [ ] Карточка «Бармен Джон»: аватар не растянут, имя, текст в кавычках-курсиве.
- [ ] Интерактивы оценивают ответ по-настоящему:
  - тренажёр баланса — выбор комбинации;
  - кислотность/сладость/горечь — слайдеры;
  - станция — размещение предметов по зонам (`_showZoneSelector`);
  - джиггер — выбор мл;
  - шейкер — тайминг;
  - сборка коктейля — порядок шагов.
  Если UI не собирает ответ — слайд **не должен** показывать «Правильно».
- [ ] Каждый интерактив: правильный ответ → зелёный фидбэк; неправильный →
      красный + пояснение; повторный тап не дублирует начисление.
- [ ] Иконка «Словарик урока» (`_openGlossary`): bottom sheet
      `DraggableScrollableSheet`, список терминов, закрытие крестиком и
      свайпом вниз. Урок без терминов → снекбар «В этом уроке нет новых терминов».
- [ ] Системное «Назад» из урока: не теряем прогресс уже пройденных уроков.
- [ ] Wisdom-уроки (блок W): фон-пергамент, кнопка «Забрать мудрость», печать.

### 1.5 Гейт терминов (`TermQuizScreen`)

- [ ] Появляется перед основным квизом, если есть невыученные термины.
- [ ] Счётчик «X/Y выучено» растёт только за верные ответы.
- [ ] После ответа: плашка «Правильно! Термин запомнен ✓» или «Не совсем…»,
      кнопка «Дальше →»; на последнем — «Завершить (n/m)».
- [ ] Экран прокручивается, overflow внизу нет (360×640 и шрифт 1.3).
- [ ] Закрытие крестиком не помечает термины выученными.
- [ ] После второго прохода гейта открывается основной квиз, а не пустой экран.
- [ ] Ачивка «все термины школы» начисляется один раз.

### 1.6 Основной квиз / экзамен (`QuizScreen`)

- [ ] Заголовок «Экзамен • N/M», прогресс-бар соответствует.
- [ ] Все типы вопросов работают и оцениваются:
      одиночный выбор, множественный выбор, matching (dropdown),
      sequence (drag), slider.
- [ ] Одиночный выбор: один тап = ответ; повторный тап ничего не меняет.
- [ ] Множественный выбор: чекбоксы, кнопка «Проверить» активируется только
      при выборе, частично верный ответ = неверный.
- [ ] Matching: dropdown открывается, список читается (фон и текст не
      сливаются), после ответа подсвечиваются пары.
- [ ] Sequence: перетаскивание работает, «Проверить порядок» показывает
      правильный порядок при ошибке.
- [ ] Slider: подпись `%`, кнопка «Готово», правильный диапазон виден.
- [ ] Нижняя кнопка: «Проверить» → «Далее» → «Завершить»; disabled-состояние
      визуально отличается.
- [ ] Правильный ответ → зелёная подпись, неправильный → красный +
      «Пояснение Джона» с внятным текстом.
- [ ] **Провал не завершает урок**: статус остаётся `available`, звёзды не
      начисляются, XP не капает.
- [ ] Проход начисляет XP/звёзды **идемпотентно** (повторный проход не
      дублирует XP, повторный идеальный проход не дублирует ачивку).
- [ ] Экран результата: «УРОВЕНЬ ПРОЙДЕН!»/«ПОПРОБУЙ ЕЩЁ!», счёт `n/m`,
      проценты, XP, монеты (если есть), 3 кубка, карточка «Дальше по пути».
- [ ] Кнопка результата: «К урокам» (проход) / «Вернуться к уроку» (провал) —
      возвращает туда, куда обещает, без чёрного экрана.
- [ ] Диалоги наград за блок показываются поверх и закрываются.

## Часть 2. Сквозные сценарии (в конце прохода, начистую)

1. [ ] **Новичок → диплом**: первый запуск → имя → пролог → A_01 →
       гейт терминов → квиз → практика → … → экзамен Level 1 → диплом
       с именем. Ни одного тупика.
2. [ ] **Провал экзамена**: урок не закрыт, можно перепройти.
3. [ ] **Офлайн**: авиарежим на весь сценарий 1 — школа работает полностью.
4. [ ] **Онлайн → офлайн**: зашли с сетью, выключили, продолжили — без
       красных экранов и вечных спиннеров.
5. [ ] **Перезапуск между шагами**: прогресс, XP, звёзды, термины, имя,
       язык и размер шрифта сохраняются.
6. [ ] **Двое устройств / чистая установка**: удалить приложение и
       поставить заново — прогресс начинается с нуля, первый запуск чистый.

## Часть 3. Визуальный контроль (единый проход по экранам)

Для каждого экрана из частей 1–2:

- [ ] **Шрифты**: заголовки — serif, тело — sans; нет «прыжков» после
      загрузки Google Fonts; кириллица и румынские диакритики (ă, â, î, ș, ț)
      отображаются корректно.
- [ ] **Цвета**: одна палитра комнаты на экран; нет синих/фиолетовых
      акцентов вне школы, нет текста «на своём фоне».
- [ ] **Отступы**: 16 px по краям, карточки одного радиуса, нет «прилипших»
      кнопок к системной навигации.
- [ ] **Тёмная тема**: приложение тёмное — светлых «пробелов» нет.
- [ ] **Safe area**: на устройстве с вырезом ничего не уезжает под камеру и
      под системные жесты.
- [ ] **Клавиатура**: на полях ввода (имя, поиск, ключ API) экран не
      «уезжает», кнопки остаются доступны.

Эти экраны в коде есть, но в навигацию v1 не входят — их либо скрываем,
либо принимаем как «бета»:

`BarManagerScreen`, `InventoryScreen`, `StopListScreen`, `PriceBookScreen`,

`GuestModeScreen`, `KioskSetupScreen`, `QrMenuScreen`, `CocktailBuilderScreen`,

недоделку раньше, чем на продукт.
