## Правила работы в ветке

- Один этап = один коммит (или 2–3 маленьких), с прогоном тестов.
- Если этап требует изменения 10+ экранов — сначала обсуждаем объём.
- Любое «улучшение» сначала проверяется тестом/скриншотом, потом
  коммитится.
- `main` не трогаем до решения о слиянии.
