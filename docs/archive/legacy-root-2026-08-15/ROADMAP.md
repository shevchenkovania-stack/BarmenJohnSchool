# 🛣️ Cocktail Bar Manager Roadmap

## ✅ Выполнено

### v1.0 — MVP (Август 2026)

#### 🎯 Основные фичи:
- **База коктейлей** — 426+ рецептов из TheCocktailDB
- **Offline-first архитектура** — Hive кэш + memory cache
- **Автозагрузка при старте** — из Hive в memory cache за 2 секунды
- **Пре-загрузка миниатюр** — все картинки загружаются при скачивании базы
- **Кэширование изображений** — CachedNetworkImage + DefaultCacheManager
- **Поиск и фильтрация** — по названию, ингредиентам, типу
- **Can Make Now** — "Что могу приготовить" из своего инвентаря
- **Cocktail Builder** — конструктор с AI генерацией рецептов
- **Мастер-класс** — AI-рецепт с профессиональными секретами бариста
- **Безалкогольные версии** — динамическое удаление алкоголя из любого коктейля
- **Избранное** — сохранение любимых коктейлей
- **Инвентаризация** — учёт ингредиентов в баре
- **Стоп-лист** — что закончилось
- **Калькулятор себестоимости** — сколько стоит каждый коктейль
- **Меню-конструктор** — создание меню для гостей
- **Guest Mode** — режим для гостей/кальянных (планшет на бар)
- **Bartender School** — обучение, quiz, дипломы (базовый)

#### 🤖 AI-функции:
- **AI генерация коктейлей** — создание рецептов по вашим ингредиентам
- **Мастер-класс (Expert Mode)** — пошаговые инструкции с профессиональными секретами
- **Баланс и интенсивность** — слайдеры для настройки вкуса (только в AI режиме)
- **Offline защита** — проверка интернета перед вызовом AI
- **Fallback** — захардкожен тестовый API ключ

#### 📴 Offline режим:
- **100% offline** — всё работает без интернета
- **Автозагрузка базы** — при старте из Hive в memory cache
- **Пре-загрузка миниатюр** — все картинки загружаются при скачивании базы
- **Fallback UI** — первая буква названия если картинка не загрузилась
- **Offline banner** — индикатор offline режима

#### 🎨 UI/UX:
- **Material Design 3** — современный UI
- **Hero анимации** — картинка "летит" при переходе на детали
- **Shimmer эффект** — загрузка картинок
- **Offline banner** — индикатор offline режима
- **Первая буква** — fallback если картинка не загрузилась
- **Слайдеры** — баланс и интенсивность (только в AI режиме)

#### 🏗️ Архитектура:
- **Clean Architecture** — разделение на слои
- **Provider** — state management
- **Hive** — offline storage
- **Repository pattern** — абстракция данных
- **Offline-first fallback** — Memory → Hive → API

#### 🔧 Технические улучшения:
- **Автозагрузка базы при старте** — не нужно вручную загружать
- **Preload from Hive** — метод для загрузки из Hive в memory cache
- **ThumbnailPreloaderService** — сервис для пре-загрузки миниатюр
- **DefaultCacheManager** — общий кэш для картинок
- **Connectivity check** — проверка интернета перед AI вызовами
- **Virgin cocktail logic** — алгоритм удаления алкоголя с проверкой liquid base
