# Анализ приложения Coin (Cocktail App)

## Что есть сейчас

Приложение — каталог коктейлей (TheCocktailDB, ~600 шт) + набор инструментов для бара.

---

## 1. ПОЛЕЗНОЕ (то, ради чего приложение стоит открыть)

### Топ-функции, которые решают реальные задачи:

| Функция | Зачем |
|---------|-------|
| **Каталог коктейлей** (поиск, фильтры, деталка) | Узнать рецепт, ингредиенты, как готовить |
| **CanMake / Инвентарь** | Отметил что есть на баре → приложение показывает какие коктейли можешь сделать. Экономит время бармена |
| **Калькулятор себестоимости** (Price Book + Cost Calculator) | Ввёл цену бутылки → приложение считает себестоимость порции. Владельцу — видеть маржу |
| **Меню (генератор PDF)** | Выбрал коктейли, нажал — получил PDF меню для печати. Экономит на дизайнере |
| **QR-меню (локальный сервер)** | Гость сканирует QR на столе → видит меню в браузере. Без установки приложения |
| **Гостевой режим (Kiosk)** | Планшет на стойке, гость сам выбирает и видит цены. Замена бумажного меню |
| **Virgin mode** | Показать только безалкогольные. Актуально |
| **Rule-based матчинг** (CocktailMatcherService) | Из того что есть на баре — что можно сделать. Бесплатно, без AI |

### Вспомогательное (нужно, но не главное):
- Избранное
- Настройки (язык en/ru/ro, единицы ml/oz)
- Оффлайн-кэш (работа без интернета)
- Поиск по названию

## 3. ЧЕГО НЕ ХВАТАЕТ (если делать реальный продукт для бара)

### Для владельца (админка):
- **Дашборд** — сегодня продано, выручка, топ коктейлей. (Папка `dashboard/` пустая)
- **История заказов** — кто, что, когда заказал
- **Списание ингредиентов** — сделали коктейль → ингредиенты списались автоматом
- **Остатки** — сколько мл осталось в каждой бутылке, пора ли заказывать
- **Роли** — Admin (владелец), Bartender (принимает заказы), Waiter (видит меню)
- **Синхронизация между заведениями** — 3 бара → один дашборд

### Для бармена:
- **Приём заказов** — уведомление "Пришёл заказ", кнопка "Принято", "Готово"
- **История заказов за смену** — чтобы отчитаться перед владельцем

### Для гостя:
- **Оплата через приложение** — Stripe / PlatiOnline / Google Pay
- **История заказов гостя** — "что я пил в прошлый раз"
