## 🤖 AI Режим — Автономность

### Проблема:
- Сейчас используется OpenAI API (требует интернет + API ключ)
- Пользователь не хочет зависеть от внешних API
- Хочет автономную систему

### Решения:

#### Вариант A: Локальная AI модель (полная автономность)
```
✅ Плюсы:
- Работает offline
- Не нужен API ключ
- Приватность данных
- Нет расходов на API

❌ Минусы:
- Нужно скачать модель (~500MB-2GB)
- Требует мощное устройство
- Ограниченные возможности

🛠️ Технологии:
- TensorFlow Lite (Flutter)
- ONNX Runtime
- llama.cpp (для LLM)
- Whisper (для speech)

📦 Модели:
- GPT-2 (small) — генерация текста
- BERT — понимание вопросов
- T5 — translation, summarization
```

#### Вариант B: Hybrid (offline + cloud)
```
✅ Плюсы:
- Базовые функции offline
- Продвинутые — через cloud
- Можно выбрать режим

❌ Минусы:
- Частичная зависимость от интернета
- Нужен backend для cloud AI

🛠️ Архитектура:
- Offline: rule-based matching, простые ответы
- Online: GPT-4 для сложных вопросов
- Fallback: если нет интернета → offline режим
```

#### Вариант C: Собственный backend (контроль)
```
✅ Плюсы:
- Полный контроль
- Можно оптимизировать costs
- Rate limiting
- Кэширование ответов

❌ Минусы:
- Нужен сервер ($50-200/мес)
- Нужна поддержка
- Масштабирование

🛠️ Технологии:
- FastAPI (Python)
- OpenAI API (с кэшированием)
- Redis (кэш)
- PostgreSQL (база)
```

### Моя рекомендация: **Вариант B (Hybrid)**

```
Фаза 1 (MVP):
- Rule-based AI для базовых функций
- Кэш популярных ответов
- Offline quiz generator

Фаза 2 (улучшение):
- Интеграция с OpenAI (с кэшированием)
- Fallback на offline если нет интернета
- Локальная модель для простых задач

Фаза 3 (автономность):
- TensorFlow Lite для offline
- Кэширование всех AI ответов
- Полная автономность
```
