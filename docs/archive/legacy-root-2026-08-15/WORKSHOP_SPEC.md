# Мастерская Молодого Бармена — Спец

## Статус
- Конструктор коктейлей СПРЯТАН из навигации (файлы сохранены в `lib/features/cocktail_builder/`)
- На его месте — Мастерская (Практика) внутри Школы

## Концепция
Образовательная практика: юзер проходит уроки → практикуется в Мастерской → получает фидбэк от Джона.
Не свободная сборка (это Конструктор), а пошаговые задания с оценкой.

## Флоу задания (5 шагов)

### 1. Вступление Джона
- Аватар Джона + текст задания его голосом
- Название коктейля, привязка к уроку
- Кнопка "Начать"

### 2. Выбор ингредиентов
- Список 8-10 ингредиентов (3 правильных + неправильные)
- Юзер тапает на те, что считает нужными
- Кнопка "Готово"

### 3. Выбор метода
- 4 карточки: Shake / Stir / Build / Muddle
- Юзер выбирает один метод
- Краткое описание каждого метода

### 4. Пропорции
- Для каждого выбранного ингредиента — настройка объёма
- Виртуальный джиггер: кнопки -5 / +5 мл
- Целевой диапазон (не виден юзеру): target ± tolerance
- Кнопка "Готово"

### 5. Результат + Фидбэк
- 3 звезды: ингредиенты / метод / пропорции
- Текст Джона: что правильно, что нет, почему
- Сравнение с эталоном
- Кнопки: "Повторить" / "В Мастерскую"

## Система оценки

| Критерий | Условие | Звезда |
|----------|---------|--------|
| Ингредиенты | Все правильные выбраны, лишних нет | ★ |
| Метод | Совпадает с эталоном | ★ |
| Пропорции | Каждый ингредиент в пределах target ± tolerance | ★ |

## Архитектурные решения

1. **Данные в Dart** — не JSON, проще загрузка, типобезопасность
2. **ProgressService** — расширяем существующий (не создаём новый)
3. **Навигация** — вкладка "Мастерская" в main_shell.dart (вместо Constructor)
4. **Конструктор** — спрятан, не удалён. Можно вернуть позже.
5. **Оценка** — rule-based, без AI
6. **Джон** — все тексты в его характере (добрый, мудрый, тёплый)

## Что НЕ делаем в v1
- Свободный режим "смешай что хочешь"
- AI-генерация рецептов
- Анимации наливания/шейкинга
- Таймеры и ограничения по времени
- Мультиплеер / рейтинги
