# Школа бармена Джона

Flutter-приложение для последовательного обучения барному ремеслу. Джон ведёт ученика через теорию, квизы, практику в Мастерской и честные дипломные требования. Основной учебный путь работает offline и не зависит от AI.

## Активная программа

- **Level 1 — Базовый курс:** 12 уроков в блоках A/B/C, квизы, Mojito, Daiquiri и Negroni как обязательная дипломная практика.
- **Level 2 — Профессиональная смена:** 12 уроков в блоках D/E/F, 104 вопроса, 12 тематических карточек и четыре практические классики: Whiskey Sour, Old Fashioned, Dry Martini и Margarita.
- Level 2 открывается только после завершения всей теории Level 1 и трёх обязательных практик минимум на 2 звезды.
- Level 3 остаётся legacy-черновиком и не загружается в основной учебный путь.

## Учебный цикл

`Карточка → история Джона → урок → квиз → Мастерская → прогресс → диплом`

Квиз завершает урок только при проходном результате. Практический XP выдаётся только за улучшение лучшего результата; перестроение UI и одинаковые повторы не начисляют награду снова.

## Запуск и проверка

```powershell
flutter pub get
flutter run
flutter test test/bartender_school/level1 test/bartender_school/level2
flutter analyze
```

Контент находится в `data/content/`, изображения карточек — в `images/`, логика школы — в `lib/features/bartender_school/`.
